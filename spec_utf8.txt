UI Specification: Python PDF Toolkit
1. Overall Theme & Aesthetic
Vibe: Modern, minimalist, developer-focused, and premium.
Design: Dark mode by default.
Architecture: Decoupled frontend (React + Tailwind CSS) communicating with a Python FastAPI backend.
Window Style: Borderless desktop app feel (conceptually), using full viewport height and width.
2. Color Palette
Main Background: Slate Dark (or similar).
Surface/Panel Backgrounds: Mix of White (majority) and light grey.
Primary Accent: Vibrant Crimson Red (#dc2626) or Electric Yellow (#eab308) for primary buttons, active states, and focus rings.
Text: Off-white for primary text (text-gray-100), muted grey for secondary text (text-gray-400).
Borders: Subtle, low-opacity borders to separate panels without being harsh (border-white/10).
3. Typography
Font Family: Modern Sans-Serif or Modern Sans Light (or system UI fonts).
Hierarchy: Clear distinction between section headers, tool names, and helper text. Clean and highly legible.
4. Layout Structure
The interface should be split into a 3-pane or 2-pane layout, mimicking a professional workspace.
A. Top Navigation Bar
Height: Slim (around 40-48px).
Content: App Logo (minimalist), App Title ("PDF Toolkit"), and standard window controls (if mimicking a desktop app) or simple settings icons (gear icon).
B. Left Sidebar (Tool Selector)
Width: Fixed (e.g., 250px).
Behavior: Acts as a persistent, vertical navigation menu allowing users to seamlessly switch between different PDF utilities without reloading the app.
Content: A vertical list of tools matching the backend capabilities:
Merge PDFs & Images
Extract Pages
Split PDF
Images to PDF
Lock PDF (Protect)
Strip Metadata (Privacy)
Extract Text
PDF to Images (Render)
Extract Images from PDF
Compress PDF
Styling: Inactive tools have muted text. The active tool has a subtle accent-colored background highlight and brighter text.
C. Main Workspace (The Canvas)
Layout: Centered content, highly spacious.
The Dropzone: A large, prominent area taking up the majority of the workspace.
Visuals: Dashed border. Inside contains an icon (e.g., a document or upload cloud) and text: "Drag & Drop PDF files here, or click to browse."
Hover State: When a file is dragged over, the dashed border should glow with the primary accent color, and the background should slightly lighten to indicate an active drop area.
Action Area: Once files are dropped, the dropzone transitions to a "File List" view showing the uploaded files as small cards.
Primary Button: A bold, solid accent-colored button at the bottom of the workspace to execute the current tool (e.g., "Merge Files").
5. Micro-interactions & Animations
Hover Effects: All interactive elements (buttons, sidebar items) should have a slight background color shift or opacity change on hover. Fast transition (e.g., duration-150 ease-in-out).
Loading States: When the "Merge" or "Process" button is clicked, it should show a sleek loading spinner (pulse or spin animation) and disable itself while waiting for the FastAPI backend to respond.
Success State: A subtle, non-intrusive toast notification appearing at the bottom right indicating "Process Complete - File Downloaded."
6. Component Details
Buttons: Slight border-radius (e.g., rounded-md). No harsh drop shadows, prefer flat design with subtle color changes.
Inputs/Forms: If text inputs are needed (e.g., for "Split from page X to Y"), they should have dark backgrounds, light text, and a bright accent focus ring.
